# CampusAI — Placement & Career Portal

The Placement & Career Portal module of **CampusAI**, a multi-agent Smart Campus Management System.

This module is built as a **standalone, integration-ready** project, designed to plug into the main CampusAI system (developed separately) without duplicating existing user, student, or authentication data.

## Status

🚧 In active development — see `docs/` for architecture and progress notes.

## Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** FastAPI (Python), SQLAlchemy, PostgreSQL
- **Auth:** JWT (shared pattern with the main CampusAI system)
